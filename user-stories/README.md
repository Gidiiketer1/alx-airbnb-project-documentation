# Airbnb Clone Backend – User Stories

## Objective

This document translates the **Use Case Diagram** into clear **user stories**. These user stories describe system functionality from the perspective of end users and guide backend development.

---

## User Stories

### 1. User Registration

**As a user**, I want to be able to register an account so that I can access the Airbnb platform and use its services.

---

### 2. User Login

**As a registered user**, I want to log in securely so that I can manage my profile, bookings, or listings.

---

### 3. View Properties

**As a guest**, I want to browse available property listings so that I can find a place that meets my needs.

---

### 4. Create Booking

**As a guest**, I want to book a property for specific dates so that I can reserve accommodation for my trip.

---

### 5. Make Payment

**As a guest**, I want to make a secure payment for my booking so that my reservation can be confirmed.

---

### 6. Create Property Listing

**As a host**, I want to create a property listing so that I can offer my property for rent.

---

### 7. Manage Property Listings

**As a host**, I want to update or delete my property listings so that I can keep my information accurate.

---

### 8. View Bookings

**As a host**, I want to view bookings for my properties so that I can prepare for incoming guests.

---

### 9. Leave Review

**As a guest**, I want to leave a review after my stay so that I can share my experience with others.

---

### 10. Admin Management

**As an admin**, I want to manage users, listings, and bookings so that the platform remains secure and trustworthy.

---

## Conclusion

These user stories represent the core interactions of the Airbnb Clone backend system and serve as a foundation for feature development and API design.
