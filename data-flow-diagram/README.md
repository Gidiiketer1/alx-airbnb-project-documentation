# Data Flow Diagram – Airbnb Clone Backend

## Objective
This document describes the Data Flow Diagram (DFD) for the Airbnb Clone
backend system. The diagram illustrates how data moves between users,
system processes, databases, and external services.

## Key Components

### External Entities
- User
- Payment Gateway

### Processes
- User Authentication
- Property Management
- Booking Management
- Payment Processing

### Data Stores
- Users Database
- Properties Database
- Bookings Database
- Payments Database
